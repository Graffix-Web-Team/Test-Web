# U-SU Engineering Challenge (Cal State LA)

Welcome to the California State LA University-Student Union (U-SU) technical assessment. This repository serves as a stripped down sandbox of our production stack, designed to evaluate your front-end development, architecture, and problem solving skills.

## Getting Started

Follow these steps to set up the development environment locally:

## Getting Started

1. Initialize the Project

```bash
yarn
```

2. Start Development Server

```bash
yarn dev
```

Visit: http://localhost:3000

## Project Structure

```bash
/pages          → Next.js routes
/modules        → Feature-based modules
/components     → Reusable UI components
/styles         → Theme + global styles
/public         → Static assets
```
